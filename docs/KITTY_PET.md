# Kitty pet: drawing and extending the pixel cat

This document explains how KittyTune's pixel-art cat (the "Kitty pet" widget) works and how to add drawings, animations, accessories or holidays. It is written for humans and coding agents alike.

> **Rule #1: never hand-edit `res/drawable/pet_*.xml`.** Everything is generated by `scripts/pet/gen_pet_sprites.py` from ASCII grids. Edit the script, run it, check the preview.

---

## 1. Overview

```
scripts/pet/gen_pet_sprites.py  ──►  res/drawable/pet_*.xml        (~2,300 small vectors)
   (ASCII grids)                     res/raw/pet_partmap.bin        (coat pixel map)
                                     ui/widget/pet/PetFrames.kt     (generated index)
                                     ui/widget/pet/PetCoatPresets.kt (patterns, generated)
```

| File | Role |
|---|---|
| `scripts/pet/gen_pet_sprites.py` | **Source of every drawing.** Sprites, animation frames, rooms, decor, accessories. |
| `scripts/pet/preview_pet_sprites.py` | PNG contact sheet for checking (renders the real layers). |
| `scripts/pet/preview_ivy.py` | Preview of Ivy's hand-made coat. |
| `ui/widget/pet/PetFrames.kt` | **Generated.** Frame name → layers. Do not edit. |
| `ui/widget/pet/PetCoatPresets.kt` | **Generated.** Patterns (solid, tabby…) as role strings. Do not edit. |
| `ui/widget/pet/PetBrain.kt` | Animations (`PetActivity`), settings (`PetSettings`, `PetConfig`), activity picking, holiday dates. |
| `ui/widget/pet/PetLayers.kt` | Stacks the 8 layers of a frame + tints. |
| `ui/widget/pet/PetCoat.kt` | Pixel-by-pixel "custom" coat (photo, editor). |
| `ui/widget/pet/PetFace.kt` | Hand-made face shapes used by the photo analysis. |
| `ui/widget/pet/PetPhotoAnalyzer.kt` | Photo → colours + pattern + eyes. |
| `ui/widget/pet/PetIvy.kt` | Ivy easter egg (hand-made look). |
| `ui/widget/pet/PetNewYear.kt` | New Year's Eve, 10→0 countdown, fireworks. |
| `audio/beat/LiveBeatTracker.kt` | Real-time tempo + beat grid of what plays (the cat dances on it). |
| `ui/widget/PetWidget.kt` | The Glance widget (RemoteViews + ViewFlipper). |
| `ui/profile/PetSettingsScreen.kt` | Setup, settings, collection. |
| `ui/profile/pet/*` | Compose preview (`PetSprite`), photo flow, coat editor, announcement sheet, Ivy reveal. |
| `res/layout/widget_pet_flipper.xml` (+ `_b`) | Widget scene: room, decor, ViewFlipper of 8 frames × 8 layers. |

## 2. Setup and running

```bash
# Python 3.10+ (the generator has no dependencies)
python -I scripts/pet/gen_pet_sprites.py app/src/main/res/drawable \
    app/src/main/java/com/alananasss/kittytune/ui/widget/pet/PetFrames.kt

# Preview (in a separate venv)
python -m venv .venv-pet && .venv-pet/Scripts/pip install resvg-py pillow   # Windows
python scripts/pet/preview_pet_sprites.py app/src/main/res/drawable \
    app/src/main/java/com/alananasss/kittytune/ui/widget/pet/PetFrames.kt sheet.png list:idle_open,dance_bob_1
```

The generator **deletes** any `pet_*.xml` it did not write: renaming a frame in the script cleans up the old one.

**Always look at the preview sheet before building.** That is where overlaps show up (an effect on top of the window, a clipped accessory, etc.).

## 3. The canvas

- **46 × 32 pixels** per frame. `OX = 8` shifts the cat right to leave room for the window (top left) and the seasonal decor (bottom left).
- **Sitting** cat: body at `(16, 21)`, tail at `(31, 20)`, 22×15 head at `(13, 8)`.
- **Loaf** cat (`pose='loaf'`): lower head, long 30×8 body.
- **Head-local** coordinates: everything on the face (eyes, accessories, tears) is relative to the head's top-left corner `(hx, hy)`. Eyes are on rows 8-10, columns 6-7 and 14-15; the nose at (11, 10-11); cheeks on row 11.
- Areas to keep effects out of: the window `x 1-11, y 2-12`, the rug `y ≥ 26`, the seasonal decor `x 0-10, y 18-30`.

### Palette (`INK`)

| Char | Colour | Use |
|---|---|---|
| `K` | dark plum | outline, face lines |
| `W` `S` | fur / shade | **tinted at runtime** (only ever on the cat) |
| `E` | iris | **tinted** with the eye colour |
| `w` | white | highlights |
| `P` `N` | pink / nose | ears, cheeks, nose |
| `M` | mouth | inside of the mouth |
| `R` `X` `V` `Q` `Y` `G` … | bright colours | hearts, notes, stars, accessories |
| `.` | transparent | |

The full list is at the top of the script (`INK = {...}`). Add a letter if needed.

## 4. How a frame is built

```python
'wave_1': cat(F_HAPPY, front=[paw(PAW_UP, 21, 6, rel=True), at(TWINKLE, 39, 4)]),
```

`cat(face, dx, dy, ...)` draws the cat, then the props:

| Parameter | Effect |
|---|---|
| `face` | facial features (combine `eyes_open()`, `EYES_HAPPY`, `NOSE`, `OMEGA`, `BLUSH`…) with `face(...)` |
| `dx, dy` | moves **the head** (looking left, nodding) |
| `lift` | lifts **the whole cat** (jump, bounce) |
| `bx` | moves **the whole cat** sideways (sway) |
| `pose` | `'sit'` or `'loaf'` |
| `tail` | `TAIL` / `TAIL_B` (wagging tail) |
| `phones=True` | music headphones |
| `hat=False` / `neck=False` | hides the user's hat / collar on this frame (e.g. when an object is in front) |
| `behind=[...]` | drawn **behind** the cat (e.g. the logo sneaking past) |
| `extras=[...]` | drawn after the body, before the head |
| `front=[...]` | drawn on top of everything |

Helpers: `at(sprite, x, y, rel=False)` places a sprite (absolute or head-local), `paw(...)` places a paw (it takes the cat's colours), `dots_rel([(r, c, 'T')])` adds pixels on the face (tears…). `recolor(sprite, 'X', 'V')` swaps a colour.

**A sprite** is a grid between `|...|`, all rows the same width (the script checks):

```python
HEART = grid('''
|.KK.KK.|
|KRRKRRK|
|KRwRRRK|
|.KRRRK.|
|..KRK..|
|...K...|
''')
```

### The exported layers

Each frame produces: `_f` fur, `_s` shade, `_m<i>` markings and `_w<i>` white parts **for each of the 6 patterns**, `_e` iris, `_i` ink (everything else). The app adds the hat and collar. Coat layers are white and tinted at runtime: that is what makes every colour, pattern and the photo coat possible without multiplying images.

## 5. Adding an animation

1. **Draw the frames** in the script (a `frames.update({...})` block), usually 2 to 4 images.
2. **Run the generator + preview**, fix.
3. **Declare the activity** in `PetActivity` (`PetBrain.kt`):
   ```kotlin
   LASER(listOf("laser_1", "laser_2", "laser_1", "laser_3", "laser_3", "laser_4", "laser_4", "laser_1"),
         400, "(⊙ω⊙)", R.string.pet_act_laser),
   ```
   - **Exactly 8 frames** (the widget's ViewFlipper has 8 slots): repeat frames to set the rhythm (`x2(...)`, `x4(a, b)`).
   - Then the duration per frame in ms, a kaomoji (plain text, **no emoji**, **no backslash** — e.g. `\m/` breaks Kotlin), the status string, and the rarity (`COMMON`, `EVENT`, `RARE`, `EXCLUSIVE`).
4. **Make it reachable** — otherwise it will never show up:
   - daily routine: `routines` in `PetBrain` (weight per time of day);
   - little surprise: `events`;
   - rare: `rarity = PetRarity.RARE` (automatically in the collection; optional filter in `raresFor`);
   - exclusive (user data): `exclusivesFor(facts)` + dynamic text in `statusText`;
   - dance: `PetActivity.DANCES`; sadness: `PetActivity.SAD_MOODS`.
5. **Add the string** to all **7** `strings.xml` files (see §9).
6. **Check** with the audit (§10), then in the emulator.

Room: `PetBrain.resolve` picks the room (`morning`, `day`, `evening`, `night`, `rain`, `sleep`, `space`). `PetSprite.kt` does the same for in-app previews.

## 6. Accessories (hats, collars)

- Drawn once in `ACC_HATS` / `ACC_NECKS`: `'name': (sprite, x, y)` in **head-local** coordinates. The script exports them for every existing head position.
- To make one selectable: add an entry to `PetHat` / `PetNeck` (`PetBrain.kt`) + its label.
- Seasonal accessories (winter beanie, Santa hat, bunny ears, April Fools' fish): `seasonalHat` / `seasonalNeck` in `PetBrain`. **The user's own accessory always wins.**
- On a frame where an object covers the head or neck, pass `hat=False` / `neck=False` to `cat(...)`.

---

## 7. Rooms, decor, holidays

- **Rooms**: `SKY` (the window's 8×8 sky) + `WALL` (wall colour). Adding a key creates `pet_room_<name>` and `pet_bg_<name>`. Special cases live in the `for room in rooms` loop (e.g. `space`: stars everywhere, no rug).
- **Decor**: `DECOR = {'name': (sprite, x, y)}` → `pet_decor_<name>`. Picked by date in `PetBrain.decorFor`.
- **Two separate settings** (important: not everyone celebrates the same things):
  - `seasonal`: season ambiance (snow, winter beanie, adoption-day cake);
  - `holidays`: holidays, **each limited to a few days** (Halloween, Christmas Dec 24-26, Valentine's Day, Easter — computed by `easterSunday`, April Fools', Fête de la musique).
- New Year: separate, in `PetNewYear.kt` (see below).

## 8. Special cases

- **Custom coat** (photo, editor, Ivy): `PetCoat` stores one role per pixel (`'0'` coat, `'1'` markings, `'2'` white) for the head (22×15), body (16×7) and tail (from the tip). `res/raw/pet_partmap.bin` tells, for each frame, which pixel belongs to which part; the app renders those layers as bitmaps. If you change `HEAD`, `BODY` or the tails in the script, **existing custom coats stay compatible as long as the sizes don't change**.
- **Photo analysis**: `PetPhotoAnalyzer` (colours per face region) → `PetFace` (hand-made shapes: muzzle, blaze, cheek, darker half…, always with the little forehead stripes). To make results prettier, tweak the **shapes** in `PetFace`, not the photo sampling.
- **Ivy**: `HEAD`/`BODY`/`TAIL` grids in `PetIvy.kt` (keep them identical in `scripts/pet/preview_ivy.py`). Ivy is male; he is the cat of KittyTune's creator.
- **New Year**: frames `count_0`…`count_10` and `ny_<year>_1..3` (banners generated for 2027-2030; extend the range in the script). The countdown is kept on the second by timers/alarms (`PetNewYear.schedule`) and by **two identical layouts** (`widget_pet_flipper` / `_b`): switching layouts forces the launcher to rebuild the ViewFlipper, otherwise it keeps its own flip clock and the numbers drift.
- **Boop while dancing**: tapping the cat while it dances plays `BOOP_DANCE` (a quick squee, headphones kept on) instead of `BOOP`.
- **Dancing on the beat**: the cat follows the music actually playing, via `audio/beat/LiveBeatTracker` (one per player slot, fed by `LiveBeatAudioProcessor` in the audio chain). It reuses the automix `BeatAnalyzer` maths on a sliding 8 s window: full-band spectral flux for the tempo, kick + snare bodies (≤ 800 Hz) for the phase (full-band flux locks onto offbeat hi-hats — that half-beat error is what a 120 BPM click-track test exposed). Beats are stamped in **media time** using `StreamMetadata.positionOffsetUs` from each flush, so the next audible beat is computed against `player.currentPosition` with no latency guess. `PetWidget.startBeatSync` restarts the widget animation right on a beat every 8 s, and immediately when the live tempo changes or the music goes quiet / comes back (`quiet` → gentle half-time sway, burst back on the drop), alternating `widget_pet_flipper` / `_b`. The automix BPM is only a fallback for the first seconds. In the app (`PetSprite`), dance frames step exactly on each heard beat. Tempo folding: 70-180 BPM (`frameMsForBpm`).

## 9. Strings (7 languages)

Every `pet_*` key exists in `values`, `values-fr`, `-de`, `-hu`, `-ru`, `-tr`, `-vi`: **the project keeps all 7 files in sync** (same number of strings). Pitfalls we hit:

- apostrophe: `d\'hiver`;
- `&`: `&amp;`;
- a string starting with `?`: `\???` (otherwise Android reads it as an attribute reference);
- placeholders: `%1$s`, `%1$d`;
- **no emoji** in strings or UI: use Material icons (`Icons.Rounded.*`) or the pixel icons (`widget_pet_heart_full`, `widget_pet_sparkle`…).

Ivy is **male** everywhere.

## 10. Checking

**Unused frames audit** (run after every addition):

```python
import re
kt = open('app/src/main/java/com/alananasss/kittytune/ui/widget/pet/PetFrames.kt', encoding='utf-8').read()
brain = open('app/src/main/java/com/alananasss/kittytune/ui/widget/pet/PetBrain.kt', encoding='utf-8').read()
frames = set(re.findall(r'put\("(\w+)"', kt))
used = set(re.findall(r'"([a-z_0-9]+)"', brain))
dynamic = {f for f in frames if re.match(r'(count_\d+|ny_\d{4}_\d)$', f)}
print(sorted(frames - used - dynamic))   # must be empty
```

**Emulator** (Git Bash on Windows: `export MSYS_NO_PATHCONV=1` before `adb shell` commands with paths):

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-x86_64-debug.apk
# reset the cat (setup, announcement sheet, easter egg…)
adb shell run-as com.alananasss.kittytune rm -f shared_prefs/kitty_pet.xml
```

To test a date (Christmas, New Year…), the simplest is a temporary build that shifts the clock in the relevant function (`PetNewYear`, `decorFor`…), then **remove that code before shipping**.
